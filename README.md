# Palbox

**بال بوكس** · Palestinian sweets and coffee from a little food truck in Barcelona.

A cinematic one-page website:

- 3D menu items you can spin 360° (drag, or press *Spin 360°*)
- A tiramisu that builds itself layer by layer as you scroll, finished with the Palbox stamp
- Baklava, mtabbak and an iced caramel latte
- Our vision, the "kids under five eat free" promise, and the road from nothing to a truck

Built as a single `index.html` with [three.js](https://threejs.org/) (r128, loaded from cdnjs). No build step: open the file in a browser, or serve it with GitHub Pages.

*Palbox is a working name.*
